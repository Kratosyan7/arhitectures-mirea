Код CPU (JavaScript)

Подсказка по API CPU Тело функции должно вернуть [r, g, b, a] с диапазоном 0..1.
Доступно: sample(dx, dy), sampleNorm(u, v), rgba(...), luminance(rgb), fract(x), mix(a,b,t), smoothstep(a,b,x), hash2(x,y), noise2(x,y), fbm(x,y), palette(t), а также x, y, width, height, uvx, uvy, cx, cy.

Подсказка по API GPU Тело функции должно вернуть vec4<f32>.
Доступно: sampleAt(ix, iy), sampleNorm(uvx, uvy), rgba(...), luminance(rgb), fractf(x), mix1(a,b,t), smoothstep1(a,b,x), hash21(vec2), noise2(vec2), fbm(vec2), palette(t), а также x, y, uvx, uvy, cx, cy.
