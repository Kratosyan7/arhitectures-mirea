# Скриншоты Logisim для ПР 12

Файл схемы: `pr12/src/logisim/pr12.circ` (Logisim 2.7.1, главная схема `simt4`,
подсхема `julia_lane`). Открывать: `java -jar .tools/logisim/logisim.jar pr12/src/logisim/pr12.circ`.

Входы выставлять не нужно: z0 четырёх пикселей и k заданы константами, сигнал
LOAD формируется автоматически на первом такте (триггер START). Схема
тактируется командой Simulate → Tick Once (Ctrl+T); один Ctrl+T — это полтакта
(переключение CLK). После открытия: 1-е нажатие — загрузка z0 (STEP = 0), далее
каждые 2 нажатия — одна итерация (STEP = k после 1 + 2k нажатий).
Если состояние сбилось — Simulate → Reset Simulation (Ctrl+R) и считать заново.

Эталонные значения проверены (`python3 verify.py`, лог `verify_log.txt`).

## 1. pr12/img/logisim_simt4.png — 4 линии в середине счёта

- Схема: `simt4` (открывается по умолчанию).
- Действия: Ctrl+T 41 раз (STEP = 20).
- Что видно: STEP = 20 (проба «20»), пробы N: lane0 = 12, lane1 = 19,
  lane2 = 20, lane3 = 20; ESC0 = 1, ESC1 = 1, ESC2 = 0, ESC3 = 0;
  ESCMASK = 0011, halt = 0. Пробы ZX/ZY: lane0 d8b5 / 11bc, lane1 d94f / f4b1,
  lane2 eb7e / fed8, lane3 fda2 / fe93.
  Смысл кадра: lane0 и lane1 уже «ушли» и замаскированы (их регистры больше не
  меняются), lane2 и lane3 продолжают выполнять ту же общую команду.
- Снимать всю схему целиком (File → Export Image или скриншот окна с масштабом,
  при котором видны устройство управления слева и все 4 линии справа).

## 2. pr12/img/logisim_simt4_final.png — останов по halt

- Схема: `simt4`.
- Действия: Ctrl+R (сброс), затем Ctrl+T 65 раз (STEP = 32).
- Что видно: STEP = 32, halt = 1; N: 12, 19, 27, 32; ESCMASK = 0111
  (три линии ушли, lane3 — точка множества, дошла до предела 32 шагов).
  Пробы ZX/ZY: lane2 1a96 / 2edb, lane3 fcb3 / f9c5.

## 3. pr12/img/logisim_lane.png — внутреннее устройство линии (с состоянием)

- Схема: `simt4`, Ctrl+R, затем Ctrl+T 3 раза (STEP = 1).
- Затем правой кнопкой по блоку lane0 → View julia_lane (или двойной щелчок
  инструментом Poke) — откроется подсхема с состоянием именно этой линии.
- Что видно: регистр RZX = f5a5, RZY = 03f4 (z после первой итерации:
  z0 = f97e + fe35·i), RN = 01, ESC = 0, WE = 1, LOAD = 0; умножители zx·zx,
  zy·zy, zx·zy, сумматор |z|², компаратор с константой 04000000 (4.0 в Q8.24),
  отбор бит 27..12 и 26..11, сумматоры с kx/ky.
- Снимать подсхему целиком.
