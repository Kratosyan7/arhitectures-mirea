# Скриншоты Logisim для практики 9

Файл схемы: `pr09/src/logisim/toupper.circ` (одна схема `toupper`, она же главная).
Открывать в Logisim 2.7.1: `java -jar .tools/logisim/logisim.jar pr09/src/logisim/toupper.circ`.
Вход `c` (8 бит) выставляется инструментом «Палец» (Poke Tool): щелчок по биту меняет 0/1,
старший бит слева. Снимать окно со схемой целиком.
Предпросмотры того, что должно получиться (нарисованы кодом Logisim без GUI):
`preview_m.png`, `preview_7b.png`, `preview_d0.png` в этой же папке.

| Картинка | Вход `c` | Что должно быть видно |
|---|---|---|
| `pr09/img/logisim_toupper_m.png` | 01101101 (0x6D, 'm') | c (hex) = 6d; оба выхода компараторов, идущие на ИЛИ-НЕ, = 0; is_lower = 1; мультиплексор выбирает вход 1 (c − 0x20); out = 01001101, out (hex) = 4d ('M') |
| `pr09/img/logisim_toupper_brace.png` | 01111011 (0x7B, '{' – следующий код после 'z') | на выходе «>» второго компаратора 1 (c > 'z'); is_lower = 0; out (hex) = 7b – символ не изменён |
| `pr09/img/logisim_toupper_cyr.png` | 11010000 (0xD0 – первый байт UTF-8 букв «а»…«п») | на выходе «<» первого компаратора 1: при знаковом сравнении 0xD0 = −48 < 'a' (так же, как после `lb` + `blt` в asm-функции); is_lower = 0; out (hex) = d0 – байт кириллицы проходит без изменений |
