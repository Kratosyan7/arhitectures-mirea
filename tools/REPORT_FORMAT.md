# Формат исходника отчёта (report.md)

Каждая практика лежит в своей папке `prNN/` (pr01 … pr12):

```
prNN/
  report.md      — текст отчёта (из него собирается prNN/Отчёт_ПР_NN.docx)
  img/           — рисунки (PNG)
  src/ …         — исходники, makefile'ы, .circ, логи запусков и т.п.
```

Титульный лист добавляет сборщик `tools/build_report.py`, в report.md его НЕ писать.
Первая строка report.md — метаданные в комментарии:

```
<!-- num: 8; title: Архитектура RISC-V -->
```

## Разрешённая разметка (сборщик понимает только это)

- `# ЗАГОЛОВОК` — раздел первого уровня (по центру, жирный, прописные):
  обязательные разделы: `# ЦЕЛЬ РАБОТЫ`, `# ЗАДАНИЕ`, `# ХОД РАБОТЫ`, `# ВЫВОДЫ`.
- `## 1 Подзаголовок` — подраздел (жирный, с абзацного отступа).
- Обычный абзац — одна или несколько строк подряд, разделитель абзацев — пустая строка.
  Внутри абзаца можно `**жирный**` и `` `моноширинный` ``. Больше ничего (ни ссылок, ни курсива).
- Списки: строки, начинающиеся с `- ` (маркированный) или `1. ` (нумерованный).
- Формула отдельной строкой: строка вида `$$ S(p) = T1 / Tp $$` (вставится по центру как текст;
  пиши обычными символами Unicode: ∧ ∨ ¬ ⊕ × ≤ ₁ ² и т.п., без LaTeX-команд).
- Рисунок — отдельной строкой:
  `![Рисунок 3 – Вывод программы в эмуляторе QEMU](img/run.png)` → картинка по центру,
  подпись под ней. Нумерация рисунков сквозная внутри отчёта, в тексте ссылаться «(рис. 3)».
- Таблица: строка `Таблица 2 – Название` (подпись над таблицей), затем GitHub pipe-таблица:
  ```
  | A | B | F |
  |---|---|---|
  | 0 | 0 | 1 |
  ```
- Листинг: строка `Листинг 4 – Название`, затем блок ```` ``` ```` (язык после ``` можно указать).
  Длинные файлы целиком в отчёт не вставлять — только значимые фрагменты (до ~80 строк),
  полные исходники лежат в `src/`.

## Скриншоты терминала

Вывод команд оформлять как «скриншот» консоли:

```
python tools/term2png.py log.txt prNN/img/run.png --title "ashot@linux: ~/prNN"
```

В log.txt первой строкой пиши приглашение и команду, например
`ashot@linux:~/pr08$ make run`, дальше — реальный вывод. Вывод должен быть настоящим
(результат реального запуска), выдумывать вывод нельзя.

## Окружение

- `source .tools/env.sh` — кросс-компилятор `riscv64-linux-gnu-gcc/as/ld/objdump`,
  `qemu-riscv64` (user-mode), `gdb-multiarch`, `fio`. sudo нет, apt install недоступен.
- Python: `.tools/venv/bin/python` (numpy, matplotlib, python-docx, mpi4py + MPICH, pillow, openpyxl);
  ставить пакеты: `.tools/venv/bin/pip install …`.
- Текст методички: `.tools/manual.txt` (pdftotext -layout), `.tools/manual_raw.txt` (без layout).
- Всё временное/тяжёлое — в `.tools/` (в .gitignore). Диск почти полон (~3.5 ГБ свободно):
  не скачивай больше ~1 ГБ, удаляй архивы после распаковки.
