# Скриншоты Logisim для отчёта ПР-11

Файл схемы: `pr11/src/logisim/pr11.circ` (Logisim 2.7.1). В нём три схемы:
`main` (сравнение), `seq` (последовательный накопитель), `par` (4 накопителя + дерево редукции).
Схема генерируется скриптом `gen_pr11.py` (`python3 gen_pr11.py pr11.circ`), проверка без GUI —
`sim.js` и `java -jar logisim.jar pr11.circ -tty table,halt`.

Общие действия в Logisim:
- открыть `pr11.circ`, выбрать нужную схему двойным щелчком в дереве слева (она станет корнем симуляции);
- **Simulate → Reset Simulation (Ctrl+R)** перед каждым снимком;
- **Simulate → Tick Once (Ctrl+T)** переключает генератор CLK на полпериода; регистры пишут по переднему
  фронту, поэтому «k тактов» = **2·k нажатий Ctrl+T** (k-й фронт приходится на нажатие 2k−1;
  после чётного числа нажатий генератор снова в нуле — так снимки аккуратнее);
- входов у схем нет (данные в ROM, тактирование — внутренний Clock), выставлять ничего не нужно;
- инструмент «рука» (Poke) не нужен; масштаб подобрать так, чтобы схема целиком помещалась в окно.
