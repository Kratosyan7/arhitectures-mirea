# parallel-integration

Практическая работа №11 «Организация параллельных вычислений»: численное
интегрирование методом трапеций (последовательная версия, multiprocessing-аналог
OpenMP, MPI), расчёт метрик и графики законов Амдала, Густафсона, Сана–Ная.

Запуск: `python -m src.main` (из каталога pr11).
